# cishu-data-format

辞书处理数据集合 NPM 包的 Demo。

## 安装

```bash
npm install cishu-data-format

##
# 1. 在项目根目录初始化（如果还没做）
npm init -y

# 2. 登录 npm
npm login

# 3. 验证是否登录成功
npm whoami
# 发布（第一次用这个）
npm publish --access public
# 修改版本号（推荐方式）
npm version patch     # 1.0.0 -> 1.0.1
# 或
npm version minor     # 1.0.0 -> 1.1.0
# 或
npm version major     # 1.0.0 -> 2.0.0

# 然后发布
npm publish
